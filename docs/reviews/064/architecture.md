# 064 Architecture Review

Verdict: FINDINGS

1. **Adapter bypasses the contract port and performs file IO.** `analysis-engine-v2/syntax-treesitter/src/commonMain/kotlin/dev/cint/v2/syntax/treesitter/TreeSitterParser.kt:16` defines a parallel `TreeSitterParser`/`ParseResult` instead of implementing `analysis-engine-v2/contracts/src/commonMain/kotlin/dev/cint/contracts/ports/SyntaxEngine.kt:9`, and `analysis-engine-v2/syntax-treesitter/src/nativeMain/kotlin/dev/cint/v2/syntax/treesitter/TreeSitterParser.kt:72` adds `parseFile` backed by `fopen`/`fread` (lines 76-92). This contradicts `docs/rewrite/module-graph.md:299-304` ("No file IO. Bytes in, packed data out") and means the spike does not prove the real adapter contract. Fix: implement `SyntaxEngine` returning `contracts.facts.SyntaxTree`, move fixture reading into `native-spike`, and remove `parseFile` from the adapter or make it caller-side.

2. **Link configuration is owned by the spike, not the cinterop module.** `analysis-engine-v2/syntax-treesitter/src/linuxX64Main/cinterop/tree-sitter.def:4` links `-ltree-sitter -ltree-sitter-c` without `-L`, while `analysis-engine-v2/native-spike/build.gradle.kts:17-18` supplies `CINT_TREE_SITTER_LIB` and the library path. Future consumers of `syntax-treesitter` such as `languages` would not link. Fix: put include, library, and linker flags in `syntax-treesitter` (def or cinterop/build) with env overrides, leaving `native-spike` link config empty.

3. **The spike is wired as a permanent module with an unused edge.** `analysis-engine-v2/settings.gradle.kts:21`, `analysis-engine-v2/build.gradle.kts:36,102`, and `analysis-engine-v2/graph-guard.json:66-67` register `native-spike` in the normal project graph, while `analysis-engine-v2/native-spike/build.gradle.kts:27` declares `:contracts` though no spike source imports it; `analysis-engine-v2/docs/rewrite/native-spike.md:85` repeats the edge. `docs/rewrite/module-graph.md` does not list this module. Result: the spike can enter `just v2-build`/CI and acquire host tree-sitter dependencies, and the graph claims a dependency that does not exist. Fix: make the spike opt-in or a separate included build, remove the contracts dependency/edge, document its removal, and update or explicitly mark the module-graph exception.

4. **The vendored fallback is not concrete for the grammar.** `analysis-engine-v2/docs/rewrite/native-spike.md:89-100` offers `CINT_TREE_SITTER_INCLUDE/LIB` as the fallback, but the checked-in `native-libs/tree-sitter` has no grammar and uses a different version (0.28 vs system 0.26.9); no source/build/install steps or pinned `tree-sitter-c` version are given. The defaults (`analysis-engine-v2/syntax-treesitter/build.gradle.kts:20`, `analysis-engine-v2/native-spike/build.gradle.kts:17`) assume system `/usr`. Fix: document a reproducible vendored recipe for both runtime and C grammar with exact tags, header/lib layout, and env invocation, or state that system packages are required and drop the fallback claim.

The native/JVM capability split is otherwise described accurately: native tree-sitter, JSON, Unix sockets, and process spawning are proven; the JVM parser stub and native HTTP/TLS limitation are admitted, and no V1 imports were found. Cinterop itself is confined to `syntax-treesitter`, with no `/home/cyp` paths, and no production module depends on `native-spike`; the remaining issues are contract drift, link-config leakage, and spike permanence.
